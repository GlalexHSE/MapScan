# MapScan — сетевой сканер с дашбордом

Сканер открытых портов на базе [Masscan](https://github.com/robertdavidgraham/masscan):
быстрое сканирование диапазонов адресов, определение сервисов по баннерам,
сравнение с прошлыми результатами, уведомления о новых находках в Telegram и
веб-дашборд для мониторинга.

Реализован **только на стандартной библиотеке Python** (3.9+) — сторонние
зависимости не нужны. Единственное внешнее требование — установленный Masscan.

## Возможности

- Многопоточное сканирование адресов средствами Masscan (асинхронное ядро + регулировка `rate`).
- Определение открытых портов и сервисов через анализ баннеров (параллельный захват по сокетам).
- Фиксация результатов в SQLite и выявление **новых** сервисов сравнением с историей.
- Уведомления о новых находках в Telegram через Bot API.
- Простой веб-дашборд MapScan: статистика, таблица сервисов, список новых находок и запуск скана из браузера.
- Периодическое сканирование по расписанию из конфигурационного файла.

## Установка

```bash
sudo apt install masscan        # внешняя зависимость
cp config.example.json config.json
$EDITOR config.json             # укажите цели, порты, токен Telegram
```

Python-зависимостей нет. Нужен Python 3.9 или новее.

## Конфигурация (`config.json`)

| Поле | Назначение |
|------|-----------|
| `targets` | Список целей: IP, диапазоны, подсети (`10.0.0.0/24`) или хосты. |
| `ports` | Строка портов для Masscan: `"1-1024,3306,8080"`. |
| `masscan.rate` | Скорость отправки пакетов в секунду. |
| `masscan.use_sudo` | Запускать Masscan через `sudo` (нужны raw-сокеты). |
| `masscan.wait` | Сколько секунд ждать поздние ответы после отправки (0 теряет результаты; рекомендуется 5+). |
| `banner_grab` | Захват баннеров: таймаут, лимит байт, число потоков. |
| `telegram` | `enabled`, `bot_token`, `chat_id` для уведомлений. |
| `scheduler` | Периодический скан: интервал в минутах, запуск при старте. |
| `dashboard` | Хост и порт веб-интерфейса. |

## Запуск

Разовое сканирование:

```bash
sudo python run.py scan
```

Дашборд + планировщик (постоянный режим):

```bash
sudo python run.py serve
# открыть http://127.0.0.1:8800
```

`sudo` нужен, если `masscan.use_sudo = true` (raw-сокеты требуют прав).
Альтернатива — выдать бинарю Masscan нужные capabilities:
`sudo setcap cap_net_raw+ep $(which masscan)` и отключить `use_sudo`.

Кнопка «Запустить скан» на дашборде запускает сканирование по целям и портам,
заданным в `config.json` (отдельного ввода целей в интерфейсе нет).

## Повседневная эксплуатация

Цели, порты и расписание задаются в `config.json` — правьте его перед запуском.

**Запустить (дашборд + планировщик):**
```bash
cd /home/kali/Desktop/scanner
sudo python run.py serve
# дашборд: http://127.0.0.1:8800
```

**Разовый скан без дашборда:**
```bash
sudo python run.py scan
```

**Проверить, что сервер работает:**
```bash
curl -s http://127.0.0.1:8800/api/stats
```

**Очистить все результаты (таблицы).** Сначала остановите сервер, затем удалите
файл БД — он пересоздастся пустым при следующем запуске:
```bash
pkill -f "run.py serve"
rm -f data/scanner.db
```
Если нужно очистить данные, не удаляя сам файл БД (например, при работающем сервере):
```bash
sqlite3 data/scanner.db "DELETE FROM findings; DELETE FROM services; DELETE FROM scans;"
```

**Завершить работу:**
```bash
# если запущено в текущем терминале — нажмите Ctrl+C
# если в фоне:
pkill -f "run.py serve"
```

## Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите `bot_token`.
2. Напишите боту любое сообщение, затем узнайте свой `chat_id`
   (например, через `https://api.telegram.org/bot<TOKEN>/getUpdates`).
3. Пропишите оба значения в `config.json` и выставьте `telegram.enabled = true`.

## Структура

```
config.example.json   образец конфигурации
run.py                точка входа (scan | serve)
src/
  config.py           загрузка и валидация конфигурации
  scanner.py          обёртка над Masscan и парсинг JSON-вывода
  banner.py           захват баннеров и определение сервисов
  storage.py          SQLite-персистенция и поиск новых находок
  notifier.py         уведомления в Telegram
  scheduler.py        периодический запуск
  dashboard.py        веб-сервер: статика + JSON API
  main.py             оркестратор и CLI
web/                  фронтенд дашборда (HTML/CSS/JS)
```

## Замечание о законности

Сканируйте только те адреса, на которые у вас есть явное разрешение.
`scanme.nmap.org` в примере конфигурации специально предоставлен для тестов.
